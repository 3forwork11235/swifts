Стрижи для Android (APK)
========================

Что это: обёртка над игрой из этой папки (index.html и скрипты). Файлы игры лежат внутри APK,
поэтому кампания и бои с ботами работают и без интернета. Для игры с друзьями нужен интернет —
приложение и сайт https://3forwork11235.github.io/swifts/ играют друг с другом по одному и тому же коду игры.
Кнопка «Копировать ссылку» в приложении даёт ссылку на сайт — друг может открыть её в любом браузере.
Приложение стартует в горизонтальной ориентации.

Установка на телефон:
  1. Перекинуть Стрижи-<версия>.apk на телефон (Telegram, кабель, Google Диск…).
  2. Открыть файл, разрешить «установку из неизвестных источников» для этого приложения.
  3. Google Play Защита может предупредить о неизвестном разработчике — «Всё равно установить».
  Android 7.0 и новее. Нужен телефон с WebGL 2 (почти все с 2017 года).

Пересобрать после изменений игры: запустить build_apk.bat.
  Версия APK берётся из const VERSION в app.js — поднимите её, чтобы обновление ставилось поверх старого.
  Инструменты сборки (JDK 17 + Android SDK) лежат в C:Usersdanilandroid-build.
  swifts-release.keystore — ключ подписи (создаётся при первой сборке). НЕ удаляйте: без него новую версию
  нельзя будет поставить поверх старой (только удалив приложение вместе с прогрессом).
